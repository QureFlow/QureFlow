# Specialty imagery

These are illustrative, AI-generated medical photographs made with the built-in image-generation tool on 2026-10-11. They do not depict QureFlow's actual facilities, clinicians, patients, or diagnostic records. The neurology monitor is decorative imagery, not a clinical scan.

The optimized WebP assets are served locally and require no external image service. Originals remain in the generation archive; the website uses 768 × 512 copies with CSS crops.

## Shared prompt

Use case: photorealistic-natural. Asset type: specialty card photograph for a professional healthcare website. Create one landscape editorial medical photograph, 3:2 aspect ratio. Natural window light, authentic material texture, quiet neutral clinic colours with occasional teal, realistic restrained photography. No illustration, 3D render, plastic glow, dramatic gradients, text, logos, watermarks, collage, split panels, borders or graphic icons. Central subject stays readable when cropped to a wide 2:1 thumbnail.
